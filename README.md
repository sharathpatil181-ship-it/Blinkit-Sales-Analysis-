# Blinkit Sales Analysis | Power BI

## 📊 Project Overview

This project analyzes Blinkit's grocery sales data using Microsoft Power BI. 
The dashboard provides insights into sales performance, product categories, 
outlet characteristics, customer ratings, and outlet locations.

The objective of this project is to transform raw grocery sales data into 
meaningful business insights using data cleaning, data modeling, DAX measures, 
and interactive Power BI visualizations.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Excel
- Data Cleaning
- Data Visualization
- Data Analysis

## 📁 Dataset

The dataset contains grocery sales and outlet-related information, including:

- Item Type
- Item Fat Content
- Item Visibility
- Sales
- Outlet Type
- Outlet Size
- Outlet Location Type
- Outlet Establishment Year
- Item Rating

## 📌 Key KPIs

The dashboard includes the following key performance indicators:

- Total Sales
- Average Sales
- Number of Items
- Average Rating

## 🔍 Key Analysis

The dashboard helps analyze how sales vary across different:

- Product types
- Fat-content categories
- Outlet types
- Outlet sizes
- Outlet locations
- Outlet establishment years

This allows users to identify sales patterns and compare the performance 
of different outlet and product segments.
